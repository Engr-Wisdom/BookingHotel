# BookingHotel

## Overview

As a software engineer, I am continually improving my software development skills by learning modern front-end development technologies such as React, Tailwind CSS, React Router, and Axios.

QuickStay is a hotel booking web application that allows users to browse hotels, explore exclusive offers, view hotel details, and read customer reviews through an intuitive and responsive user interface.

The purpose of creating this software was to strengthen my understanding of component-based architecture, state management, page navigation, responsive web design, and API integration using modern JavaScript frameworks and libraries.

## Running the Project

Clone the repository.

```bash
git clone https://github.com/Engr-Wisdom/cse310.git
```

Navigate to the project folder.

```bash
cd QuickStay
```

Install all dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

If a backend server is available, run the following command:

```bash
npm run server
```
